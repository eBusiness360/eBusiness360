### Commercial module

**[Maxcode_SupplierOrder](https://www.ebusiness360.fr/modules/commandes-fournisseurs/)** — purchase order management inside the Magento admin.
Create, send and receive supplier orders without leaving Magento. Drop-shipping from customer orders, partial receipts line by line, automatic MSI stock updates, branded e-mail + PDF to suppliers, multi-site aware. FR + EN.
